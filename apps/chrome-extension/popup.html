First-time setup (Windows)

Open PowerShell in your checkout folder and run this command once:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File packages/computer-use/install-host.ps1 -ExtensionId imnnjncafjnhhebhjkaoiobegpjahnhb

This installs the local connector for your Windows account. Start a client configured with the Open Harness CUA MCP tools, then reopen this popup. Use the same computer-use folder in the client configuration. Full setup examples are in packages/computer-use/README.md in your checkout. For a custom folder, set OPEN_HARNESS_CUA_HOME in PowerShell or pass -HomeDir with that same absolute folder.
