First-time setup (Windows)

Open PowerShell in your T3 checkout folder and run this command once:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File packages/computer-use/install-host.ps1 -ExtensionId imnnjncafjnhhebhjkaoiobegpjahnhb -HomeDir "$PWD\.t3\computer-use"

This installs the local connector for your Windows account. Start a T3 thread or another client configured with the computer-use MCP tools, then reopen this popup. Use the same computer-use folder in the client configuration. Full setup examples are in packages/computer-use/README.md in your checkout.

Save a signed-in session locally, then import it into a browser profile in T3.
